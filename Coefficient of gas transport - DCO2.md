DCO<sub>2</sub> = frequency X TV<sup>2</sup> 
A DCO<sub>2</sub> of 40-60 mL<sup>2</sup> /kg<sup>2</sup> /s will generally achieve PaCO<sub>2</sub> in the mild permissive hypercapnoeic range

If you want to set the tidal volume to achieve a DCO2 of 60, derive by formula 
```
60= (frequency * TV * TV)/weight * weight
```

If you want to calculate if the displayed DCO2 is 60 or not
```
displayed DCO2/(weight * weight) = 60
```
