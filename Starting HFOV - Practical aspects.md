1. Set up appropriate monitoring equipment. TcCO2 is useful to have. 
2. Note PEEP and delta P being given in the conventional ventilation
3. Ensure no secretions in the airway. Better to do suction before initiating HFV to prevent deterioration. 
4. Set appropriate MAP (for OLV and prevention of overdistension that will increase the chance of barotrauma and also increase the PVR)
	1. For elective HFOV - set as given in [[Lung recruitment maneuver]]
	2. For rescue HFOV - same method to find optimal MAP as given in the [[Lung recruitment maneuver]] with starting pressure set 2-3 cm H2O higher than the MAP given in CV if the I:E ratio 1:2 or 1:3 and equal to the MAP in CV if I:E ratio is 1:1. See [[FRC and MAP during HFOV]] for explanation
5. FiO2 needed is set in conjunction with MAP as explained in the [[Lung recruitment maneuver]]
6. Set appropriate amplitude to achieve adequate ventilation but prevent dynamic barotrauma.
	1. Initial value can be 1.5 times the delta P during CV (or some sources say twice the set MAP in HFOV)
	2. Lower frequencies need higher amplitude to achieve same DCO2
	3. Traget DCO2 is 40-60 ml2/kg2/s
	4. If TV monitoring is not possible, look for appropriate chest wiggle.
	5. If rescue HFOV for treating hypercapnia avoid sudden changes in pCO2 (and therefore in cerebral circulation) by targeting a gradual reduction of pCO2 2-3 mmHg/minute
7. If VG is available - set the target tidal volume to meet the DCO2 target as given above. P max should be + 5 cm the pressure needed to deliver the set TV![[Screenshot 2023-02-10 at 12.09.08 PM.png]]
8. Frequency: Choose a frequency of 8-15 Hz depending on the size of the baby, lung compliance, and resistance so as to ventilate around the corner frequency. ![[Screenshot 2023-02-10 at 12.36.21 PM.png]]
	1. A good number to remember is 8-10-12
	2. MAS: 8
	3. Term with lung disease: 10
	4. Preterm with HMD: 12
